## 结论

1. **倾向性假设被数据证实**：first 策略周一课时是周五的 4 倍（33.3% vs 8.3%)，
   时段枚举顺序造成的周初堆积是真实且严重的。
2. **去倾向性同时提升了完成率**（+0.84pp，多排 39 个班）：周初热门时段不再被无偏好
   课程提前耗尽，61 个 first 失败的班在 random 下排上了（新增失败仅 22 个）。
   这支持"均匀放置 ≈ Least-Constraining Value 一阶近似"的论证。
3. **副作用**：random 把 21.8% 的课推到晚间 9-11 节（first 仅 8.7%）——均匀 ≠ 可取，
   晚间时段对师生不友好。改进方向：在 balanced 策略得分中加入"时段可取性先验"
   （如晚间惩罚项），在均衡与作息友好之间折中。
4. 共同失败的 519 个班与策略无关，属数据层硬约束（教师周次/教室资源/约束矛盾），
   对应失败归因模块的输入。
5. 耗时几乎不变（4.17h vs 4.18h），策略切换无性能代价。
