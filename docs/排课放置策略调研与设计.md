# 排课放置策略：倾向性问题调研与改造设计

2026-06-11。对应代码：`utils1.py` 顶部「放置策略」配置块、`schedule_class` 选择逻辑。

## 1. 问题：原始方案的倾向性

当前贪心流程：`schedule_one_round` 按"最受约束优先"(MCF) 选出可行方案数最少的教学班后，
`schedule_class` 做两个放置决策，均存在系统性倾向：

1. **教室选择**：取可行方案数最多的教室（平票取先遍历到的）。方案数多 ≈ 教室大、约束少，
   导致小课占大教室、热门通用教室被提前耗尽（容量错配）；
2. **时段选择**：取该教室的**第一个**可行方案，而 `new_check_period_availability`
   按 天→节次 顺序枚举，导致课程系统性堆向**周初早间**；周四五下午、晚间长期空置，
   后续偏好"周一上午"的受约束课程反而抢不到位置。

这两个决策都属于 CSP 文献中的 **value ordering（值排序）** 问题：变量排序（选哪门课）
已用 MCF/most-constrained-first 处理，但值排序（选哪个时段教室）用的是朴素 first-fit。

## 2. 文献中的对策

| 方法 | 思想 | 代表文献 |
|---|---|---|
| Least-Constraining Value (LCV) | 选择对剩余未排课程可行域破坏最小的值 | Haralick & Elliott, *Increasing tree search efficiency for constraint satisfaction problems*, AIJ 1980 |
| GRASP 随机化贪心 | 在贪心候选集（RCL）中随机选择，消除确定性倾向，可多次重启取最优 | Feo & Resende, *Greedy randomized adaptive search procedures*, J. Global Optim. 1995 |
| 负载均衡/分散软约束 | ITC-2007 curriculum-based 赛题将 MinWorkingDays（课程分散到多天）、RoomCapacity（容量适配）列为标准软约束；UniTime/IFS 的值选择按多准则加权 | Di Gaspero, McCollum & Schaerf, *ITC-2007 Track 3 报告*; Müller, *Constraint-based timetabling*, 2005 |
| Best-fit 教室分配 | 装箱问题的 best-fit：选容量"刚好够"的教室，保留大教室给大课 | 经典 bin-packing 启发式；Lewis, *A survey of metaheuristic-based techniques for university timetabling*, OR Spectrum 2008 |

精确 LCV 需要对每个候选值重算所有剩余课程的可行域（本项目规模下每步代价 ≈ 一轮完整资源
统计 × 候选数，不可行）。常用近似是**负载均衡**：把无特殊偏好的课推向当前占用率低的时段，
等价于"为后续课程保留竞争激烈的资源"，即 LCV 的一阶近似。

## 3. 本项目的实现（utils1.py）

三种策略，`set_placement_strategy(strategy, seed)` 或 `--strategy` 切换：

- **first**（默认）：原始方案，逐字保留，作为消融基线；
- **random**：GRASP 式——收集全部可行 (教室, 时段方案) 组合，带种子等概率随机选一个。
  纯去倾向性对照组，用于区分"随机性本身"与"质量导向"各自的贡献；
- **balanced**：负载均衡放置，得分最低者胜：

  ```
  score = 0.6 × 时段全局占用率 + 0.25 × 教室容量浪费率 + 0.35 × 晚间节次占比
          (+ 1e-9 随机抖动破平)
  时段全局占用率 = 方案覆盖的(天,节)单元在全体可排教室、本课教学周内的平均占用比例
  容量浪费率   = (教室座位数 − 课容量) / 座位数
  晚间节次占比 = 方案覆盖单元中第 9 节及以后的比例（作息友好先验）
  ```

  权重为模块常量 `BALANCED_W_SLOT / BALANCED_W_ROOMFIT / BALANCED_W_EVENING`，可做
  参数敏感性分析。晚间惩罚的依据：first vs random 对比实验显示纯均匀化把晚间课时
  占比从 8.7% 推高到 21.8%（见 实验记录_放置策略对比_first_vs_random.md）——均匀
  不等于可取。当前权重下，纯晚间方案的固定罚分 0.35，相当于日间占用率 58% 的负载
  （0.35/0.6），即只有当日间普遍排到近六成满时，课才开始让位到晚间；该项只参与候选
  排序，不影响可行性（可行方案全在晚间的课仍正常排晚间）。

设计约束：只改 `schedule_class` 一处（首轮排课与调课失败重排共用的唯一放置入口），
`first` 分支与原实现逐字一致（包括"全部教室无方案时仍返回首个教室"的边界行为），
随机源带固定种子保证可复现。

## 4. 消融实验用法

```bash
python test_for_school.py --strategy first      # 基线
python test_for_school.py --strategy random --seed 2026
python test_for_school.py --strategy balanced --seed 2026
python run_pipeline.py --strategy balanced      # 整条流水线透传
```

建议对比指标：排课完成率、调课轮次数、时段分布熵（按天/节统计课时直方图的均匀度）、
教室容量利用率（KRL/SKZWS 均值）、周一上午 vs 周五下午课时比。多种子重复 random
策略可给出方差棒。
