## 结论

1. **first 的倾向性被证实**：周一课时是周五的 4 倍（33.3% vs 8.3%），"第一个可行时段"
   造成的周初早间堆积真实且严重。
2. **random 与 balanced 都治好了周初堆积、完成率都比 first 高约 0.9pp**：周初热门时段不再
   被无偏好课提前耗尽，多排上约 40 个班。
3. **random 的代价**：把 21.8% 课时推到晚间（first 仅 8.7%），且容量利用率未改善（60.7%）
   ——印证"均匀 ≠ 可取"。
4. **balanced 全面占优**：在拿到 random 同等完成率与周分布均衡的同时，
   - 晚间占比压到 **3.7%**（比 first、random 都低）——晚间惩罚项生效；
   - 教室容量利用率从 61% 升到 **84.7%**、使用教室数 472→461——best-fit 让小课不再占大教室；
   - 时段熵 0.852 介于 first 与 random 之间，因 balanced 有意避开晚间、按规则择优，
     并非追求绝对均匀（绝对均匀正是 random 的副作用来源）。
5. **balanced 是三者中最适合落地的方案**：消除倾向性、提升完成率、改善资源适配、
   兼顾作息友好。
