LLM增强的启发式贪心智能排课算法
——以西安交通大学排课为例

统计学 · 数学与统计学院

一、选题的科学依据

课程排课是高校教学管理的核心难题，其本质是在多重硬、软约束下对有限资源（教室、教师、时间段）进行组合分配的优化问题，已被证明为 NP-hard 问题[1,3]：随着课程、班级、教室规模增大，精确求解时间呈指数级增长。以西安交通大学 4000 余教学班的真实规模为例，整数规划模型将产生数万个变量与约束，难以在可接受时间内求解。

传统方法（整数规划、遗传算法、禁忌搜索、模拟退火等）在中小规模实例上可得可行解，但面对大规模、高约束密度的真实场景时，求解效率与可行性难以兼顾；元启发式方法依赖初始解质量，且解不可解释。更现实的困难在于：排课需求大量以自然语言形式表达（教师偏好、教室要求、时间限制），结构化解析依赖大量人工干预，严重制约系统可用性。

理论意义：排课问题是计算复杂性理论、约束规划与多目标优化的经典检验平台；应用价值：将教务人员从繁重易错的手工排课中解放，把排课周期从数周缩短至小时级，并优化教室、师资等资源配置。其底层逻辑可迁移至医护排班、考场编排、生产线调度等同类问题。

近年来大语言模型（LLM）在语义理解与推理上的突破，为破解"自然语言需求解析"这一瓶颈提供了新路径。将 LLM 的语义能力与传统优化算法的求解能力相结合，构建兼具自动化程度高与系统可解释性强的智能排课方法，正是本课题的切入点。

二、国内外研究动态

2.1 课程排课问题的理论与算法

过去二十年，求解大学课程时间表问题的方法可归纳为四类[5,7]：运筹学方法（图着色、整数线性规划、约束满足）、元启发式（遗传算法、禁忌搜索、模拟退火、蚁群、粒子群、变邻域搜索）、智能新方法（混合方法、模糊理论、聚类）与多智能体方法。许多工作采用"构造阶段 + 改进阶段"的两阶段框架；Gaspero 与 Schaerf[14] 提出的多邻域局部搜索，对本研究调课阶段的邻域选择具有直接参考价值。整数规划虽能给出最优性保证，但 Daskalaki 等[2] 的实践表明其耗时随规模急剧增长（92 门课需 95 分钟），难以应对西安交通大学量级。

2.2 LLM 与调度优化的融合趋势

研究者已开始探索 LLM 在调度问题中的三类角色：

  • 约束解析与建模：NL4Opt 竞赛、Holy Grail 2.0、OptiMUS 等实现自然语言到可求解数学模型的端到端转化；
  • 启发式设计：FunSearch、EoH 将 LLM 与进化搜索结合以发现新型启发式规则，在经典组合优化问题上超越人工设计；
  • 可解释决策：TRACE-cs[24] 将符号推理与 LLM 结合，为排课查询生成可验证的自然语言解释。

综合来看，LLM 已在语义解析、启发式设计、结果解释三方面各有进展，但将三者统一整合为完整排课流程的工作尚属空白，构成本研究的核心创新空间。

三、研究目标及研究内容

本研究提出一种融合大语言模型与启发式贪心算法的智能排课方法，构建"排课—分析—反馈"闭环优化机制，实现自然语言理解、组合优化与可解释决策的协同。

3.1 问题形式化

设教学班集合 $C$、教学日集合 $D$、每日时段集合 $P$、教学周集合 $W$、教室集合 $R$、教师集合 $T$、班级集合 $B$。每个教学班 $c$ 关联教师集合、班级集合、周学时 $z_c$、容量需求 $q_c$、偏好时间 $\Phi_c$ 与避免时间 $\Psi_c$。排课即寻找映射，为每个 $c$ 分配教室 $r$、若干连续上课时段三元组 $(d, s, h)$（星期、起始节、连续节数）及教师授课子周集合，使得任意资源在任意 $(w,d,p)$ 处唯一占用（硬约束 $\mathcal{H}$），并最大化时段偏好、教学楼/校区、教室类型等软约束满足度（$\mathcal{S}$）。优化目标以最大化排课完成率为首要、软约束累计满足度为次要。

3.2 算法流程（五阶段）

  1. 自然语言解析与约束结构化：LLM 对原始排课需求文本进行语义抽取，映射为统一结构化约束；
  2. 语义嵌入聚类与分批：对课程属性向量化，聚类划分为组内约束相似、组间冲突低的子集，降低单次搜索复杂度；
  3. "最受约束优先"(MCF) 启发式贪心排课：每轮选可行方案数最少的教学班优先安排，避免后期资源耗尽；
  4. 约束松弛与变邻域迭代调课：对失败课程逐步放松软约束、腾挪已排课程，多轮提升完成率；
  5. LLM 驱动的失败归因与反馈：对残余失败集合，结合排课日志生成原因解释与调整建议，形成闭环。

4.1 已建成的系统核心模块

系统已实现完整流水线，并在两套真实高校数据上完成端到端实验：西安交通大学 4000 余教学班经贪心与变邻域调课后完成率 99.1%，剩余 36 个失败案例均有结构化归因；另一所高校近 5000 教学班首轮 87.7%、调课后提升至 98.1%。两套数据排课耗时不超过 3 小时，调课 12–30 分钟，验证了跨院校适用性与时间高效性。模块包括：基础排课引擎、自然语言偏好解析、语义嵌入聚类、变邻域调课优化、失败归因与建议、端到端流程与可视化。

4.2 本阶段新增工作

在中期框架基础上，本阶段重点完善了 LLM 增强环节、数据治理与放置策略，并搭建了消融实验所需的基础设施：

  • LLM 排课前合理性复核：采用"规则定量 + LLM 语义"两层架构。先由规则程序生成结构化证据（含教师跨课程偏好冲突的全局检测——规则逐班检查覆盖不到的交互问题），再由 LLM 对命中交互信号的教学班做语义级一致性推理，识别隐性矛盾，给出风险等级与可操作建议；
  • LLM 失败归因与调整建议：复用规则版诊断证据（枚举拒绝构成、教师占用指纹等），由 LLM 输出固定分类的失败主因、面向教务人员的自然语言解释与分条调整方案，构成"归因—调整—重排"闭环；
  • 数据治理：建立四张标准表的自动校验与一键数据转换能力；修复教师表缺失（补全 540 名教师、按工号去重），并对周学时越界等异常课程自动导出"待教务确认"清单，量化数据质量对完成率的影响；
  • 一键全流程编排：将数据校验→检查→排课→调课→归因→可视化→报告串联为单脚本流水线，支持断点续跑与 LLM 环节可选，为消融实验提供统一入口。

4.3 重点专题：排课倾向性问题及其改造

原始贪心在选出"最受约束"教学班后，固定选取可行方案数最多的教室的第一个可行时段。由于时段按"星期→节次"顺序枚举，导致课程系统性堆积于周初早间，且大教室被小课占用。这属于约束满足中的值排序（value ordering）问题——变量排序已用 MCF 处理，值排序却仍是朴素的 first-fit。

为此设计两种可切换的新放置策略，并保留原始方案作为消融基线：

① random（GRASP 式随机化贪心）[Feo & Resende 1995]：在全部可行候选中等概率随机选择，作为"纯去倾向性"对照。对教学班 $c$，记其可行候选集为 $A(c)=\{(r,a)\}$，则

$$ (r^\ast, a^\ast) \sim \mathrm{Uniform}\big(A(c)\big) $$

② balanced（负载均衡 + best-fit，带作息先验）：这是本阶段新提出的方案，原仅有代码实现，现补充其数学形式。它不再随机，而是对每个候选 $(r,a)$ 计算综合代价并取最小者——近似约束满足中的最小约束值（Least-Constraining Value, LCV）思想，把课优先放到最不占用后续资源的时段：

$$ (r^\ast, a^\ast)=\operatorname*{arg\,min}_{(r,a)\in A(c)}\; \Big[\, w_\rho\,\rho(a)\;+\;w_\omega\,\omega(r,c)\;+\;w_\varepsilon\,\varepsilon(a)\,\Big] $$

其中三项分别为时段全局占用率、教室容量浪费率与晚间惩罚。记方案 $a$ 覆盖的时段单元集合为 $\mathrm{cells}(a)$，全体可排教室集合为 $R$，教学周集合为 $W_c$：

$$ \rho(a)=\frac{1}{|\mathrm{cells}(a)|}\sum_{(d,p)\in \mathrm{cells}(a)} \frac{1}{|W_c|\,|R|}\sum_{w\in W_c}\sum_{r'\in R}\mathbb{1}\big[r'\text{ 在 }(w,d,p)\text{ 已占用}\big] $$
$$ \omega(r,c)= \begin{cases} (\,\mathrm{cap}_r-q_c\,)/\mathrm{cap}_r, & \mathrm{cap}_r> q_c>0\\[2pt] 0, & 0<\mathrm{cap}_r\le q_c\\[2pt] 1, & \mathrm{cap}_r\le 0 \end{cases} \qquad \varepsilon(a)=\frac{1}{|\mathrm{cells}(a)|}\sum_{(d,p)\in \mathrm{cells}(a)}\mathbb{1}\big[p\ge p_{\text{eve}}\big] $$

权重取 $w_\rho{=}0.6,\,w_\omega{=}0.25,\,w_\varepsilon{=}0.35$，晚间起始 $p_{\text{eve}}$ 为第 9 节。$\rho$ 项把课推向当前最空闲时段（为后续受约束课程保留热门资源），$\omega$ 项实现 best-fit 教室分配（小课不占大教室），$\varepsilon$ 项作为作息友好先验——三项均为软导向，不破坏可行性：若某课可行候选全在晚间，仍照常排晚间。

在某高校真实数据（已治理，weeks=20）上对三种策略各跑一次首轮排课（仅首轮、未调课，同种子）：

五、下一步的工作计划

框架完善（进行中）

将 LLM 排课前检查与失败归因从规则版升级为语义推理版，提升对多样表述、隐性矛盾与多重耦合冲突的覆盖；对 balanced 策略的权重与晚间起始节次做参数敏感性分析。

自然语言解析对比实验

模块级消融实验

设置五组变体（w/o LLM-Parse、w/o Consistency、w/o Embedding、w/o MCF、w/o LLM-Diag），并将本报告的放置策略三方对比纳入 w/o-MCF 相关分析，在小型 ITC-2007、中型 ITC-2019、大型 XJTU 三套数据上评估可行性、质量、效率与可解释性指标。

基准数据接入与可解释性评估

接入 ITC 标准基准数据集；参照 TRACE-cs 的人工评估方法，从正确性、可操作性、简洁性三维评价失败原因解释的质量。
