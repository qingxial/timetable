# 参数化排课修复工具

`scripts/repair_courses.py` 从现有 Excel 重建已知资源占用，在明确允许的偏好内尝试完整补排或少量挪课。输出可审计候选，不覆盖 Excel，不调用 LLM。统一工具接口另提供数据更正、分阶段补排、联合优化、冲突解释与保留旧方案的续排，见 [Agent排课工具接口](Agent排课工具接口.md)。

## 运行

使用 Python 3.10+、pandas、openpyxl，从仓库根目录运行：

```bash
# 严格约束基线
python scripts/repair_courses.py --output-dir repair-runs/strict-001

# 明确允许调整普通偏好，特殊要求仍保留
python scripts/repair_courses.py \
  --config configs/repair-conservative.json \
  --output-dir repair-runs/conservative-001
```

每次选择新输出目录。默认读取：

- `智能排课基础数据/提取的基础数据表_converted/课程表_split_merged.xlsx`
- 同目录 `教室表.xlsx`，以及存在时的 `班级表.xlsx`
- `排课结果/调课后的整体结果_特殊放宽.xlsx`
- `排课结果/调课失败的排课失败课程_特殊放宽后.xlsx`

可用 `--course-file`、`--room-file`、`--schedule-file`、`--failed-file` 替换路径。`proposal.json` 包含源 SHA-256、参数、逐课诊断、前后安排、完整候选和增量校验，`diagnosis.csv` 便于筛选。审计更正和新工作流使用统一工具，不直接修改工作簿。

## 参数

JSON 不认识的字段或不支持的调整会报错；统一工具要求显式传 `allowed_changes`。

| 参数 | 含义 |
|---|---|
| `target_ids` | 精确教学班ID；空列表表示本次传入目标全部 |
| `allowed_changes` | 仅支持 `time_preference`、`building_preference`、`historical_room`；空列表保持约束 |
| `time_scope` | `strict` 保持偏好；`same_day` 原偏好日换节；`weekdays` 可换工作日；`configured_days` 使用显式 `days` |
| `reviewed_soft_time_ids` | 已审核可调整的学院指定时段；须同时允许 `time_preference` |
| `locked_ids` | 禁止改动课程 |
| `movable_ids` | 原课可移动白名单，默认空 |
| `max_moved_courses` | 整批最多移动原课程数，0–3，默认0 |
| `max_candidates_per_course` | 每课候选上限；达到上限披露截断 |
| `max_search_nodes` | 整批候选检查数上限 |
| `time_limit_seconds` | 生成候选及搜索预算，不含读取工作簿 |
| `days`、`periods` | 日0–6对应周一至日，节次1–11；默认工作日1–8节 |
| `single_period_starts` | 默认 `odd` 奇数起点；`any` 补充单节偶数起点，不改两节及更长块的起点网格 |
| `max_weekly_hours` | 整数周负荷支持上限，默认8，可设1–77；不是现实可用时数 |
| `max_blocks_per_day` | 每门课每天最多块数，默认1，可设1–11 |
| `filter_fixed_occupancy` | 默认false；仅0移动可设true，在生成阶段排除固定占用 |
| `additional_forbidden` | 追加禁排；不能解除周二5–8节校级禁排 |

无放宽容量、校区、必要类型、指定教室、教师/班级冲突或总学时的开关。原数据共占教室/免查班级标志保持原值，不新增豁免。类型名称仅覆盖输入表达的设备条件，无设备明细时不能声称验证了额外设备。

与结构化偏好一致的“学院：…；时间：周Xn.m”默认遵守；只有加入 `reviewed_soft_time_ids` 才能按授权调整。精确文本“仅周六周日排课”另按周末硬约束识别，不能因允许调整时间偏好而改到工作日；其他自由文本返回 `unreviewed_special_requirement`，不由模型自行忽略。

## 数据更正与集中授课

源 `LLXS` 与 `ZXS×周数` 不一致或小数周学时不能直接取整。`redistribute_hours` 核对原值，以 LLXS 为总量，指定每个原周的整数负荷；也可明确选择 `balanced_frontload` 生成候选。该计划保持总量及每个原教学周，但不证明哪周多上一节是唯一正确答案；选择规则和证据须留在审计中。

`set_capacity` 要求有来源且明确冻结的实际人数；`replace_classes` 要求真实完整班级映射；`quarantine_incomplete_segments` 仅在有效行已满足逐周及总量时隔离多余坏行。`set_one_off_week` 另支持零周学时、一个授课块可完成的正整数 LLXS：确认具体周且 `weeks_confirmed: true` 后，才可将周域缩至源周集合中的该周；真实9门 LLXS为2，尚未执行。操作字段见 [工具接口](Agent排课工具接口.md)。

更正只在内存生效，保留原值、新值、证据及 `source_hashes.corrections`，源 Excel 不变。已有授权可执行证据齐全的操作，无需重复确认；缺失的数据事实不能靠授权或猜测补足。

集中授课须有足够授课块。例如16周学时按两节块需8块，一周最多7日，一日一块仍无候选。提高 `max_weekly_hours`、`max_blocks_per_day` 扩大表达范围，仍逐节检查禁排、偏好和资源。固定占用预筛仅适用于不挪课；解释释放占用的效果时不得使用已被该占用预筛删掉的域。

`repair_with_fallbacks` 在已授权日/节范围内依次尝试日间、晚间、周末，先前成功安排保持不变。原失败清单外的新目标用 `extend_repair_proposal`：显式新增ID，独立验证并保留种子成功，原 `failed_path` 保持不变。结果 `scope_extension` 单列扩域目标和新增数，不重写失败表掩盖口径变化。

## API 与算法范围

统一接口提供十个工具、`TOOL_SCHEMAS`、`dispatch_tool` 及 JSON 命令行。底层 API 用于已有数据对象：

```python
from scripts.repair_data import load_dataset
from scripts.repair_courses import repair

data = load_dataset(course_path, room_path, schedule_path)
result = repair(data, target_ids=["你的教学班ID"], config={
    "allowed_changes": ["time_preference"],
    "time_scope": "same_day",
    "max_moved_courses": 1,
    "movable_ids": ["审核过的可移动教学班ID"],
    "time_limit_seconds": 60,
})
```

`repair` 是有界启发式：先完整插入，再尝试最多3门直接阻塞课程重放；被挪课程全部完整排回才接受，否则回滚。没有完整递归冲突链，不保证全局最优。

`optimize_local_repair` 对显式邻域的完整课程候选联合回溯，分阶段优化补排数、移动数和质量；`quality_frontier` 固定补排数及候选域比较移动预算。它们是真实有限域算法，并非 Phillips/Lindahl 原论文 MIP 复现。保留域内最优不等于全局最优。

`explain_conflict` 用固定模型上的三值oracle和 QuickXplain。候选/模型不完整、时间或节点耗尽须保留UNKNOWN；显式受限域证明也只针对该候选范围。冲突核须逐项删除复验，释放占用的解释不等于原课已排回。详见 [三篇论文接入设计](三篇论文接入设计.md)。

## 验证和计量

多教师责任周逐行合并后与教学周相交，每条课表记录使用自己的周次、教室和节次。班级匹配用完整名称，不使用“班级数达到8就免查”的旧启发式。“全校/全院”需真实选课或班级映射。

按唯一教学班ID计数，多教师行、多个课段不重复算课程。虚班和母课另给口径：子班经常继承整门母课 LLXS，应按子段周次负荷汇总后核对母课，不能逐个子班要求母课总量。

零小时倒置节次只记导出警告；非零课的缺周/无效时段默认保守冻结已知资源，不能当空闲。只有符合条件且留有审计的隔离可解除相应不确定占用。`new_conflicts=0` 只证明改动对已知资源没有新增冲突，历史冲突、未知选课关系及原课时差异另查。
