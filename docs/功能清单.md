# 智能排课系统 · 功能清单

> 按「基础功能」与「进阶功能」分层整理。基础功能是排课的核心引擎，进阶功能是在此之上应对真实教务复杂需求的能力。

---

## 一、基础功能（核心引擎）

### 1. 数据加载与建模
- `Basic_Data.py`：定义 Course / Classroom / Teacher / Class 四个数据模型，各自带 20周×7天×11节 的三维时间表。
- 从双行表头 Excel（第一行中文名、第二行英文字段）加载课程/教师/教室/班级；支持中文表头前缀回退识别（英文字段名缺失时仍能加载）。
- 数值字段（ZXS/KRL）类型容错；SFXYPK 等开关字段兼容 int/str 两种存法。

### 2. 预筛选（pre_selection）
- 只保留「需要排课(SFXYPK=1) + 需要教室(SFXYJAS=1) + 上课周次有效 + 周学时在(0,8] + 有教师周次/课程类别/校区」的教学班。
- 静默剔除不满足条件的课（如理论学时 LLXS=0、周学时 ZXS=0/超范围）。

### 3. 课程聚类分批
- `course_clustering.py`：按课程特征聚类，分批调度，降低单批规模、提升可控性。

### 4. 首轮贪心排课
- `test_for_school.py` + `utils1.schedule_class`：分批 + 分聚类，为每个教学班在「硬约束全满足」的候选集内贪心落子。
- 放置策略可切换：`first`（方案数最多教室的首个时段）/ `random`（GRASP 式）/ `balanced`（负载均衡，消融实验用）。

### 5. 硬约束检查（`tryloadlimit.new_check_period_availability`）
- **教师冲突**：按教师责任周（RWJSZCDM ∩ 教学周）逐周检查，同一教师同时段不重排。
- **班级冲突**：学生班级同时段不重排。
- **教室冲突**：同一教室同时段不重排。
- **时间偏好/禁排**：Prefer_Time 偏好窗口内优先、unavailable_Time 禁排时段规避。
- **校级约束**：全校周二(5-8节)禁排。

### 6. 上课日模式生成
- `new_generate_day_patterns`：按周学时生成「星期-节次」组合，遵循「每天最多 2 节连排」的教学惯例，杜绝 4 节连排。

### 7. 时间偏好解析
- `build_preferences` / `parse_cell_to_struct`：把「周三(1-2节)」「周六全天」「全周(1-2节)」「[绑定组]」等自然语言约束解析成结构化的周/天/节次窗口。

### 8. 调课（变邻域局部重排）
- `reschedule_by_adjusting.py`：为首轮失败课腾资源——挪开已排的匹配课程 → 排入失败课 → 给挪开的课找新位置；逐级松弛（放宽教室池 / 放宽班级冲突 / 放宽周学时匹配）。

### 9. 挪课-回滚（事务性）
- `clear_placement` / `place_placement`：临时移除、重新落子、失败回滚，保证挪课过程可逆、不弄丢已有成果。
- 清除按「归属判断」只清确属本课的占位（已修复无条件清除导致的教师双占/教室悬挂 bug）。

### 10. 结果输出与合并
- 首轮结果、调课结果、整体合并结果（教学班/课程/教师/教室/星期/节次/上课周次）导出 Excel。

## 二、进阶功能（真实教务复杂需求）

### 1. 单双周不同周次排课
- `scripts/fix_odd_even_weeks.py`：解析「X单 / X双」等源数据（如"结束周=17单/16双"），重新生成 23 位周次代码 SKZCDM，让只在单周或双周上的课正确参与排课。

### 2. 奇数周学时拆虚班（@W / @B）
- `scripts/split_odd_zxs.py` + `merge_virtual_jxb.py`：奇数 ZXS（3/5/7）拆成「偶数每周(@W) + 双周(@B)」两条虚班，算法层 0 改动即可支持；配对虚班共享教师/班级，LCV「避同天」软约束协调。

### 3. 小数点学时自动规划周次与周学时 ★
- `scripts/split_fractional_zxs.py` + `local_reschedule_fractional.py`
- **动机**：原 `math.ceil` 把 3.5 学时向上取整成每周 4 节，系统性超排 14.6%。
- **方案**：以整数总学时 T（理论学时 LLXS）为锚点，把小数周学时课按**周次前后分段**：
  - `@FA`＝前段几周、每周高节数（前段满）；`@FB`＝后段几周、每周低节数。
  - **恒等式** `H·a + L·b = T` 保证**零残差**（如 T=20/N=6 → 前2周×4节 + 后4周×3节 = 20）。
  - **B 优先**（H、L 全偶数，全 2 节连排块，520 门）/ **A 兜底**（带余除法，对任意 T、N 恒有整数解，9 门）/ **不拆**（ZXS>8 集中课）。
- **无损保证**：字段/周次严格划分/学时守恒 round-trip 自检 529/529 全过。
- **局部重排**：在已排的冻结状态上事务性重排（快照→清除旧 ceil 占用→试排 @FA/@FB→提交或回滚），不全量重跑；484 门精确重排、零数据丢失。

### 4. 体育课上课地点允许冲突（IF_ROOM_CONFICT）★
- 开关 `IF_ROOM_CONFICT=1` → 该课不写教室占用，天然多班共占同一场馆（体育馆/操场）；=0/缺省 → 正常独占检查。

### 5. 班级冲突允许开关（IF_CLASS_CONFICT）
- 开关 `IF_CLASS_CONFICT=1` → 该课不参与班级冲突检查（如学生自选的场景）；=0/缺省 → 正常检查。

### 6. 理论学时过滤（LLXS）
- `LLXS=0/空` 的课（无理论课时）自动不参与排课。

### 7. 软约束自动修复（最小偏离软偏好）★
- `scripts/soft_preference_repair.py`
- 针对「(教师×单一偏好格)物理超订」的课（多为体育课，偏好格被同教师同偏好班占死）。
- **不丢偏好**：偏好仍是主约束，仅对物理无解者做**最小偏离**——按「偏好内＞同偏好天换节次＞同偏好节次换天＞其它格」的字典序，挪到最近可行格，守住教师/班级/教室/禁排/校级全部硬约束。
- 运行时守卫只修「偏好本身合法仅被占」的课，数据问题课不硬塞。

### 8. 局部增量重排（不全量重跑）★
- 在已完成排课的冻结状态（pickle）上，只对目标课清除→重排，其余固定不动；事务性快照/回滚保证零丢失。分钟级完成，替代 16 小时全量重跑。

### 9. 失败归因分析
- **规则版** `postfailure_analysis.py` + `scripts/enrich_failure_attribution.py`：逐课诊断「卡在哪一步（偏好窗口/教室/教师/班级）+ 具体根因 + 证据 + 修改建议」。
- **LLM 版** `llm_failure_analysis.py`：LLM 驱动的自然语言归因与调整建议。
- **预检** `preflight_schedule_checks.py` / `llm_preflight_check.py`：排课前的冲突/可行性预检。

### 10. 结果分析与可视化报告
- `scripts/build_run_report.py`：自包含 HTML 报告，含总览 KPI、贡献分解、偏好满足率、连排结构、上午/下午分布、负载均衡、时段热力图（标注校级禁排）、座位利用率、教室时间利用率、教师工作量、失败归因。
- `generate_report*.py` / `analysis_report.py` / `scheduling_visualization.py`：多套报告与图表。

### 11. 数据治理与对账
- 静默跳过对账（哪些课未进排课及原因）、静默字段修正、体育课避免排课时间补充、教师表补全、转换数据校验。

### 12. 特殊要求·分级约束放宽（任课老师>类别/学院>全校）★
- `scripts/special_requirements.py`：按**作用范围定级**把 PKYQMS/一句话策略解析成 L3/L2/L1，冲突取最高级（`classify`/`parse_policy`/`resolve`）。
- `tryloadlimit.new_generate_day_patterns(..., max_block, block_template)`：默认每天≤2连排；有特殊要求时允许 4/7/8 连排、跨天 3+4（默认参数零回归）。
- `scripts/apply_special_requirements.py`：全校/类别级禁排已摊平在每行禁排列时，回写做「外科减法」——L3 要求覆盖低级禁排只删该行被覆盖段（存量零改动）。
- `scripts/reschedule_special_relax.py`：对失败课在调课阶段**分级放宽再试排**——桶A（早上偏好被类别禁排挡住→删该段）、桶B（仅周末+高学时→小数分段 @FA/@FB + 周末 >2 连排、守恒零残差）；物理硬约束不放宽，事务提交/回滚。从 229 门失败救回 53 门（4437→4490=96.23%）。

### 13. 统一软约束松弛总记录
- `scripts/build_relaxation_ledger.py`：把「时间偏好偏离 + 类别禁排覆盖(L3>L2) + 连排放宽+小数分段」汇成一张 `软约束松弛总记录.xlsx`（119 条），逐课记录松弛类型/级别取舍/详情/结果。

### 14. 全链驱动
- `scripts/run_full_pipeline_after_reschedule.py`：调课后一键串跑「软偏好合并 → 小数拆分重排 → **特殊要求分级放宽** → **统一松弛总记录** → 失败归因 → 报告 → 悬挂校验」。
