### Issue #14 · 每天最多 2 节 + 奇数 ZXS 拆虚班
**问题**：用户希望每节课每天最多 2 节（即使 7-8 节也只 2 节），同时奇数 ZXS（3/5/7）走"主时段每周 + 辅时段双周"实现。

**核心策略**（IO 层拆/合，算法层 0 改动）：

#### 拆分通式：奇数 ZXS = (ZXS-1) 每周 + 2 双周
| 原 ZXS | 虚班 A | 虚班 B | 验证 |
|---|---|---|---|
| 3 | ZXS=2 每周 | ZXS=2 双周 | 18×2 + 9×2 = 54 = 18×3 ✓ |
| 5 | ZXS=4 每周 | ZXS=2 双周 | 18×4 + 9×2 = 90 = 18×5 ✓ |
| 7 | ZXS=6 每周 | ZXS=2 双周 | 18×6 + 9×2 = 126 = 18×7 ✓ |
| 1 | 保持不拆 | — | — |

#### JXBID 命名约定
- 原 JXBID: `202520261PHY1234.005`
- 虚班 A: `202520261PHY1234.005@W`（Weekly）
- 虚班 B: `202520261PHY1234.005@B`（Biweekly）
- 用 `@` 避免与原命名碰撞；合并 `jxbid.split('@')[0]`

#### 虚班 B 的 SKZCDM
原 SKZCDM ∩ 起始周奇偶决定的双周掩码：
- 起始周奇 → 用单周（3, 5, 7, ...）
- 起始周偶 → 用双周（2, 4, 6, ...）
- 保证"起始周必须上课"且总学时严格守恒

#### 算法层为什么 0 改动
虚班 A 和 B 共享同一个 `teacher_week_map` 和 `classes` → 教师/班级冲突天然处理；MCF 的 Ω(c) 计算会自动反映"配对虚班已占资源"。

#### 软约束避同天（用户已敲定要做）
在 LCV 打分里加项 $w_\delta \cdot \delta(a, c^*)$：
$$\delta(a, c^*) = \mathbb{1}\{a \text{ 占用天} \cap \text{paired 虚班已占天} \neq \emptyset\}$$

实现要素：
- Course 加 `paired_jxbid: str = None`
- Course 加 `scheduled_days: set`（落子时同步），O(1) 查询
- $w_\delta = 0.5$（待实验调优）
- 调课阶段按轮次降权：轮 1 用 0.5，轮 2+ 降到 0

#### 工作量
| 层 | 文件 | 改动 |
|---|---|---|
| 前处理 | `scripts/split_odd_zxs.py`（新建） | 拆奇数 ZXS、加 JXBID 后缀、写 `课程表_split.xlsx` |
| 算法 | `utils1.py` / `Basic_Data.py` | Course 加 paired_jxbid + scheduled_days；LCV 加 δ 项 |
| 后处理 | `scripts/merge_virtual_jxb.py`（新建） | 排课结果去 `@W/@B` 后缀、合并 |
| 配置 | `test_for_school.py` | 改 course_excel 指向拆后副本 |

约 100 行新代码 + ~10 行算法改动。
