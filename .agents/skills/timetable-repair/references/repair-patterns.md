# 错误模式与修复决策

本文件用于识别原因和选择动作。状态码只是首个发现的阻塞，不是课程全部问题；至少同时检查课时、静态房间、班级覆盖和源约束表达。以下均须基于本次输入与授权。

| 模式 | 识别证据 | 有效动作 | 验收与停止条件 |
|---|---|---|---|
| 人数口径使教室全被筛掉 | KRL与源人数上限一致；同校区/类型最大容量小于KRL；原表另有实际人数 | 核实冻结人数后 `set_capacity`，否则保留需求并核实真实场地/正式分班方案 | 先重算静态候选，再联合试排；静态有房间不保证时间可排。没有冻结证据不把实际人数直接当新需求 |
| 确实缺少合适设施 | 同校区所需类型为0，或采用已确认人数后仍大于该类型最大容量 | 补核真实库存、设备适配；必要时形成类型/校区替代或分班决策 | 当前六种更正没有添加教室、改必要类型或拆班操作。补充真实数据后建立新输入版本并重验，不把不存在的房间写入方案 |
| 班级覆盖不明或忽略标记未生效 | 泛指全校、空班级、畸形字段；同时核对IF_CLASS_CONFICT原值 | 有完整真实映射用 `replace_classes`；已有逐课免查授权用 `set_class_conflict_check`；源已免查却仍被coverage阻塞是加载器兼容问题 | 只消除班级覆盖阻塞，保持其他元数据错误；报告班级/学生检查排除范围，不称恢复了真实映射 |
| 周学时×教学周与LLXS不等 | 逐行核对LLXS、ZXS、SKZCDM及教师责任周 | 以已确认LLXS为总量，`redistribute_hours` 指定整数周负荷或明确采用均衡前置策略 | 全部原周仍有正负荷、合计LLXS不变；不同周分配属于教学计划选择，不能取整丢小时或重复母课LLXS |
| 零周学时但有一次课总量 | ZXS=0且正整数LLXS能在一个授课块完成 | 确认源周域内具体周，再 `set_one_off_week` | 未确认具体周不自动挑“最方便”的周；这类课程单列，不误认为无需授课 |
| 多余坏课段造成保守冻结 | 缺周/无效日期记录存在；其余有效记录已满足完整周负荷和LLXS | `quarantine_incomplete_segments`，以原行数作前置条件 | 只隔离多余坏行；原有效记录逐行保留。有效课时不足时不能用此法“解锁” |
| 模型上限误挡集中课 | 源周负荷与LLXS相符，但周上限/每日块数不足 | 显式设置 `max_weekly_hours`、`max_blocks_per_day`；0移动可用 `filter_fixed_occupancy` | 保持总量、周、块长和硬禁排；参数上限不是现实可用时数，不能随意截成8学时 |
| 已有房间但时间/偏好域太窄 | 静态教室候选非空，查看偏好、硬禁排与资源占用 | 在已授权域内用 `repair_with_fallbacks`；偏好调整需 `allowed_changes` 和适用白名单 | 各阶段仅与调用方域取交集；精确“仅周六周日排课”仍为硬约束，不能因放宽偏好排到工作日 |
| 固定占用阻塞 | 完整域/声明保留域中存在占用冲突，非静态设施缺口 | `explain_conflict` 识别阻塞，再在授权可动集合内 `optimize_local_repair` | 占用标签的诊断释放不等于移动完成；旧课必须完整排回。不得用UNKNOWN作为删约束依据 |
| 已可排但扰动/夜间周末代价高 | 相同输入、同目标且同候选域下已有可行方案 | `quality_frontier` 固定补排数，比较移动预算及明确的质量权重 | 同步披露时间/节点预算与截断；不同数据或验证范围不能当作纯算法性能比较 |
| 只因预算不足未找到 | search_limit、候选截断或UNKNOWN | 在同一授权模型下适度增候选/节点/时间，记录预算差异 | 重复增加预算仍无进展时回到原因证据，不能无限重试或宣称无解 |
| 技术候选有业务语义空洞 | 类型为空、人数为0、场地名与课程用途明显不匹配 | 单列业务待核，补充真实人数、用途及场地适配证据 | 不把“source检查通过”升级为现实可发布。retry/extend都锁定旧成功，不能拿它们修改已成功的种子课程 |

## 多因问题的处理顺序

先准备同一课程所有需要的更正，再在同一有效输入下联合复验。例如：班级免查可以露出学时矛盾，纠正学时后仍可能没有教室。日志应保留已解决原因和剩余原因，不把状态由data_issue变为no_matching_room记成新产生的故障。

静态房间候选是满足启用、校区、容量、必要类型、指定房间和未放宽房间偏好的集合，尚未扣除时间占用。此集合为空，说明当前这些条件组合无供给；这不是现实中永远不可能，也不意味着增加晚间/周末或挪走别的课就会有效。

## 用于论文和方法评估的拆分

每次实验单独标注以下来源：数据事实更正、候选教学计划、授权验证范围调整、模型表达扩展、求解/优化算法。按相同有效源哈希、目标、候选域和预算比较算法；逐课免查、人数改变或增加周末形成另一情景。

Phillips对应先提高完整补排数、再减少扰动的局部修复思路；Lindahl对应固定完成水平后的质量/调课数量权衡；QuickXplain对应可复验的冲突解释。当前前两项为有限候选回溯实现，不是原论文MIP复现；三者都不能创造教室、人数或学生关系。
